# INDEX

The entry point of the handbook, 5 pages. Generated by `scripts/make-index.sh` from the front matter of the pages: do not edit it, change the `summary:` or `keywords:` of the page and run the script (Tier 0 fails when this file is out of date).

Start here: `grep -i WORD INDEX.md` for the service, the symptom, the tool or the name you look for, then open the page; a page over 40 KB is read by section (`scripts/page-outline.sh PAGE`, see CLAUDE.md). Columns: the page, its title, its `status`, its size in KB, the question it answers (`summary:` of the page) and its `keywords:`. Not listed: `CLAUDE.md` (the rules, loaded in every session) and `README.md` (what only it says).
